# afterSource — 고도화 후보 목록

이 파일은 현재 Phase 1 설계에서 의도적으로 제외되었으나,
추후 고도화 단계에서 적용 가치가 있는 기술/개념을 보존한다.

각 항목은 **어떤 에이전트에 적용되는지**, **왜 지금은 아닌지**, **어느 Phase에 적합한지**를 명시한다.

---

## NI 관련

### 지식 그래프 (Knowledge Graph)
- **적용 대상**: NF 또는 별도 에이전트
- **내용**: RDF 트리플 구조로 뉴스 이벤트-기업-거시경제 변수 간 관계를 모델링. "금리 인상 → 다국적 기업 수익성 영향" 같은 논리 체인 구성 가능.
- **왜 지금은 아닌가**: 기반 파이프라인이 안정화되기 전에 붙이면 복잡도가 폭발함. NER 구조화가 먼저 검증되어야 의미 있음.
- **적합 Phase**: Phase 3

### AI 생성 뉴스 탐지 (BiLSTM 기반)
- **적용 대상**: NC 또는 NF
- **내용**: BiLSTM + Word2Vec 임베딩으로 AI 생성 스팸/가짜 뉴스를 98% 이상 정확도로 식별.
- **왜 지금은 아닌가**: Phase 1에서는 수집 소스를 Bloomberg, Reuters, 연합인포맥스 등 신뢰 소스로 제한하므로 출처 신뢰도 필터가 이 역할을 대신함.
- **적합 Phase**: Phase 2 (소스 확장 시점)

## TA 관련

### 동적 매개변수 최적화
- **적용 대상**: TR
- **내용**: 변동성이 낮은 구간에서는 짧은 기간 지표로 민감도를 높이고, 고변동성 구간에서는 기간을 늘려 노이즈를 제거. RSI 기준값을 시장 체제에 따라 동적으로 조정 (예: 고변동성 장에서 70 → 80).
- **왜 지금은 아닌가**: 고정 기준값으로 먼저 검증이 끝난 뒤 동적 조정을 도입해야 비교 기준이 생김.
- **적합 Phase**: Phase 3

### 체제 감지 통계 도구 (HMM, KS-Test, CUSUM)
- **적용 대상**: TR
- **내용**: Hidden Markov Models로 숨겨진 시장 상태(강세/약세/횡보) 확률적 추론. KS-Test로 현재 가격 분포가 과거 모델 분포와 유의미하게 달라졌는지 감지.
- **왜 지금은 아닌가**: 현재 TR은 규칙 기반 불안정 감지 수준. 통계 도구는 충분한 과거 데이터가 쌓인 후 의미 있음.
- **적합 Phase**: Phase 3

### 볼린저밴드 / MACD / 스토캐스틱
- **적용 대상**: TC 계산 지표 확장
- **내용**: Phase 1의 MA/RSI/거래량 외 추가 지표. 각각 추세 추종, 모멘텀, 변곡점 포착 역할.
- **왜 지금은 아닌가**: 지표가 늘어날수록 TR에서 지표 간 충돌 처리 로직이 복잡해짐. 기반 3종 검증 후 확장.
- **적합 Phase**: Phase 2

## IB 관련

### 사용자 프로필 기반 적응형 브리핑
- **적용 대상**: IP
- **내용**: "공격적 트레이더"에게는 높은 변동성 종목 우선 노출, "보수적 투자자"에게는 안정적 종목 중심 브리핑.
- **왜 지금은 아닌가**: 현재 핵심 가치는 "판단은 사람이 한다"이며, 시스템이 사전 필터링하면 이 원칙과 충돌할 수 있음. 기반 신뢰가 쌓인 후 선택적 도입.
- **적합 Phase**: Phase 4

---

## 포트폴리오 관련 (Phase 4 전용)

### 변동성 / 베타 / 샤프 비율
- **적용 대상**: 신규 에이전트 (Portfolio Risk Agent)
- **내용**: 포트폴리오 수준의 리스크 지표. 개별 종목 분석이 안정화된 후 포트폴리오 전체 리스크 측정에 사용.
- **적합 Phase**: Phase 4

### 손절/익절 라인 자동 제안
- **적용 대상**: 신규 에이전트
- **내용**: ATR 기반 동적 손절선 계산. 현재 변동성을 고려한 리스크 허용 범위 제안.
- **적합 Phase**: Phase 4

### 시나리오 시뮬레이션
- **적용 대상**: 신규 에이전트
- **내용**: "만약 금리가 0.25%p 오른다면" 류의 가정 기반 시뮬레이션. 지식 그래프와 연동 시 효과 극대화.
- **적합 Phase**: Phase 4

## 데이터 소스 관련

### DART / SEC EDGAR 공시 연동
- **적용 대상**: NC 소스 확장
- **내용**: 한국 DART 및 미국 SEC EDGAR의 공시 데이터 직접 수집. 현재는 뉴스를 통해 간접 수집.
- **왜 지금은 아닌가**: 각 소스의 API 형식과 인증 방식이 완전히 다름. 기본 파이프라인 안정화 후 추가.
- **적합 Phase**: Phase 2

### 중앙은행 발표 직접 수집 (Fed, 한국은행, ECB)
- **적용 대상**: NC 소스 확장
- **내용**: 공식 발표문 직접 수집. 현재는 맥락 소스를 통해 간접 수집.
- **적합 Phase**: Phase 2

## 센타우르 모델 고도화 (TR + CA)

### 동적 가중치 할당
- **내용**: 현재 시장 체제(횡보/추세/고변동성)에 따라 TR이 MACD 비중을 낮추고 RSI 비중을 높이는 방식으로 해석 로직을 실시간 변경.
- **왜 지금은 아닌가**: Phase 1은 고정 기준값 기반. 체제 감지 통계 도구가 먼저 도입되어야 함.
- **적합 Phase**: Phase 3

### 확신 점수 (Confidence Scoring) 기반 거래 보류
- **내용**: 지표 간 충돌이 심하거나 Out-of-Distribution 상황일 때 에이전트가 스스로 "판단 불가"를 선언하고 사람에게 경고. 현재 TR의 confidence 필드를 확장한 개념.
- **적합 Phase**: Phase 3
